교육용 미디어 도구

수업 자료를
내 PC에서 간단하게.

YouTube 링크를 붙여넣고 형식을 고르면 끝. 설치 후 start.bat을 더블클릭하면 내 PC에서 바로 실행되는 무료 도구입니다.

ZIP 내려받기 설치 방법 보기

Windows 10·11 기준 · Python, ffmpeg 필요

주의사항

교육용 목적에 한해 사용하세요.

  • 본인이 만든 영상, 저작권자에게 허락받은 영상, CC 라이선스 영상처럼 이용 권한이 있는 콘텐츠만 받으세요.
  • 받은 파일은 수업과 교육 활동 안에서만 사용하고, 재배포·재업로드·상업적 이용은 하지 마세요.
  • 교육 목적이라도 저작권법이 허용하는 범위를 넘으면 안 되며, 이용에 따른 책임은 사용자에게 있습니다.
  • YouTube 이용약관은 허가 없는 다운로드를 제한합니다. 이 도구는 각자의 PC에서만 실행하며, 공개 서버로 운영하지 마세요.
기능

필요한 것만 담았습니다.

형식 5가지

원본 화질, 1080p, 720p, 480p, MP3(192kbps) 중에서 고릅니다.

실패 원인 진단

비공개·연령 제한·삭제·접근 거부 등 실패 이유와 해결 방법을 알려주고 로그를 남깁니다.

자동 업데이트

start.bat으로 켤 때마다 yt-dlp를 최신으로 맞춰 YouTube 변경에 대응합니다.

내 PC 전용

서버가 내 컴퓨터 안에서만 열립니다. 다른 기기에서는 접속되지 않습니다.

설치 (Windows)

처음 한 번만 준비하면 됩니다.

  1. Python 설치

    python.org에서 설치합니다. 설치 첫 화면에서 "Add python.exe to PATH"를 꼭 체크하세요. 명령 프롬프트를 쓸 줄 안다면 아래 명령도 됩니다.

    winget install Python.Python.3.13

  2. ffmpeg 설치

    영상·음성을 합치고 MP3로 바꾸는 데 필요합니다. 시작 메뉴에서 "명령 프롬프트"를 열고 아래 명령을 실행하세요.

    winget install Gyan.FFmpeg

  3. 프로그램 내려받기

    ZIP 파일을 받아 원하는 폴더에 압축을 풉니다. (압축 파일 안에서 바로 실행하면 안 됩니다.)

  4. start.bat 더블클릭

    Python·ffmpeg를 확인하고 yt-dlp를 설치·업데이트한 뒤, 브라우저에서 http://127.0.0.1:8765가 자동으로 열립니다. 검은 창을 닫으면 프로그램이 꺼집니다.

    "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.

Node.js가 설치되어 있으면 YouTube의 보안 확인을 더 잘 처리합니다. (선택)
macOS·Linux: 압축을 푼 폴더에서 pip3 install -r requirements.txt 후 python3 server.py

사용법

링크 넣고, 고르고, 받기.

  1. YouTube 영상 주소를 복사해 입력칸에 붙여넣습니다.
  2. 형식을 고릅니다. 수업 송출·학생 배포용은 1080p 또는 720p를 권장합니다.
  3. 다운로드 시작을 누르면 진행 상황이 표시되고, 끝나면 브라우저 다운로드 폴더에 저장됩니다.
문제 해결

자주 묻는 질문

다운로드가 실패해요.

화면에 실패 원인과 해결 방법이 표시되고, "실패 로그 받기"로 자세한 기록을 볼 수 있습니다. "접근 거부(403)"나 "추출기 오류"라면 프로그램을 끄고 start.bat으로 다시 켜서 yt-dlp를 업데이트하세요.

원본 화질 파일이 재생되지 않아요.

원본 화질은 4K·AV1 코덱이거나 mkv 파일인 경우가 많아 오래된 PC나 기본 플레이어에서 재생되지 않을 수 있습니다. VLC 같은 플레이어를 쓰거나 1080p·720p로 다시 받으세요.

720p를 골랐는데 화질이 낮아요.

원래 영상에 그 화질이 없으면 있는 화질 중 가장 가까운 것으로 저장됩니다.

다른 컴퓨터나 휴대폰에서 접속이 안 돼요.

정상입니다. 이 도구는 실행한 PC 안에서만 열리도록 만들어졌습니다. 다른 PC에서 쓰려면 그 PC에도 설치하세요.

"Python을 찾지 못했습니다"라고 나와요.

Python을 설치할 때 "Add python.exe to PATH"를 체크하지 않은 경우입니다. Python 설치 프로그램을 다시 실행해 "Modify"에서 PATH 옵션을 켜거나, 다시 설치하세요.

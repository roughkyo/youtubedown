      주의사항
      
교육용 목적에 한해 사용하세요.

      
    
        
  • 본인이 만든 영상, 저작권자에게 허락받은 영상, CC 라이선스 영상처럼 이용 권한이 있는 콘텐츠만 받으세요.
    • 
        
  • 받은 파일은 수업과 교육 활동 안에서만 사용하고, 재배포·재업로드·상업적 이용은 하지 마세요.
    • 
        
  • 교육 목적이라도 저작권법이 허용하는 범위를 넘으면 안 되며, 이용에 따른 책임은 사용자에게 있습니다.
    • 
        
  • YouTube 이용약관은 허가 없는 다운로드를 제한합니다. 이 도구는 내 PC에서만 실행되며 공개 서버로 배포하지 마세요.
    • 
      


      
화질을 고를 때 주의하세요.

      
    
        
  • 원본 화질은 4K·AV1 코덱인 경우가 많아 오래된 PC나 기본 동영상 플레이어에서 재생되지 않을 수 있습니다. 파일 크기도 매우 큽니다.
    • 
        
  • 원본 화질은 mp4에 담을 수 없는 코덱이면 mkv 파일로 저장됩니다. 재생이 안 되면 VLC 같은 플레이어를 쓰세요.
    • 
        
  • 수업 화면 송출이나 학생 배포용으로는 1080p 또는 720p가 가장 안정적입니다.
    • 
        
  • 영상에 해당 화질이 없으면 그보다 낮은 화질로 받아집니다. 예: 240p 영상은 720p를 골라도 240p로 저장됩니다.
    • 
      

    


    

      업데이트 안내
      
yt-dlp를 주기적으로 업데이트하세요.

      
YouTube가 사이트를 바꾸면 오래된 yt-dlp로는 다운로드가 실패하기 쉽습니다. yt-dlp는 설치한 지 90일이 지나면 업데이트를 권장합니다.


      

        설치된 버전
        확인 중...
      


      
    
        
  1. 이 서버를 실행한 터미널에서 Ctrl + C로 서버를 끕니다.
    2. 
        
  2. 아래 명령을 실행합니다.
          
    
            python -m pip install -U yt-dlp
            
          
    
        
    3. 
        
  3. python server.py로 서버를 다시 실행합니다.
    4. 
      

      
다운로드가 실패했을 때 진단에 "접근 거부(403)", "추출기 오류", "yt-dlp 업데이트 필요"가 나오면 먼저 업데이트해 보세요.
